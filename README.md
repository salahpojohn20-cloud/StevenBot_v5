## 📦 Installation

```bash
pkg update && pkg upgrade -y
pkg install nodejs-lts git ffmpeg python unzip

git clone https://github.com/salahpojohn20-cloud/StevenBot_v5.git

cd StevenBot_v5

npm install

npm install-scripts approve --all

node index.js
```
